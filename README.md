# 🛠️ Pentester's Swiss Army Knife

Welcome to the **Pentester's Swiss Army Knife**! This repository is designed to be the ultimate starting point for beginner penetration testers. It combines a curated learning path, a set of essential cheat sheets, and a TUI-based automation script to help you navigate the complex world of security auditing.

## 🚀 Quick Start

### 1. Installation
Clone the repository and make the scripts executable:
```bash
git clone https://github.com/LirikThePyDev/swisspen.git
cd swisspen
chmod +x scripts/knife.sh tools/install_tools.sh
```

### 2. Setup Tools
Run the automated installer to get the essential tools on your Kali or Ubuntu machine:
```bash
sudo ./tools/install_tools.sh
```

### 3. Launch the Knife
Start the menu-driven interface:
```bash
./scripts/knife.sh
```

## 📦 What's Inside?

- **`scripts/knife.sh`**: A menu-driven wrapper for common pentesting tasks.
- **`cheat-sheets/`**: Quick references for Nmap, Metasploit, SQLmap, and more.
- **`RESOURCES.md`**: A comprehensive guide on where to learn, what to read, and how to practice.
- **`configs/`**: Optimized configuration templates for your tools.

## 🛡️ Ethical Guidelines
Penetration testing is a skill that must be used responsibly.
- Always obtain written permission.
- Never target systems you don't own or have authorization for.
- Report your findings responsibly.
- Read the [DISCLAIMER.md](DISCLAIMER.md) before proceeding.
